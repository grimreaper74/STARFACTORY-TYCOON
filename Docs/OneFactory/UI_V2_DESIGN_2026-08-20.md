# Player UI v2 design (2026-08-20)

The owner's gameplay mockup is the definitive target; this maps each of
its surfaces onto the now-real gameplay systems and phases the build.
Mouse-first UMG replaces the canvas/hotkey developer HUD; every key
binding survives as a shortcut. All text FText/string tables
(localisation requirement); palette D colour language.

Beyond the mockup (new since it was drawn): reputation, fleet wear +
SERVICE DUE, financial state colouring, rescue contracts, day clock,
save/load. These live in the top bar and detail panel.

## Phases (each suite-gated)

- **U1 Top bar (UMG)**: brand, contract counter, cash, day clock,
  transport buttons wired to the operations subsystem, alert bell,
  reputation/wear chips. Replaces the canvas management band.
- **U2 Flow panel (UMG)**: clickable department cards (status dot,
  units, rate), selected-card outline, click focuses the camera on the
  department (FrameProductionLine already does this).
- **U3 Detail panel**: selection detail + one primary action button in
  context (Place order / Pass QA / Rework / Service plant / contract
  view).
- **U4 World-space alerts**: toast widgets anchored at the alerting
  station's transform.
- **U5 Polish**: card thumbnails from preview renders, title screen,
  pause menu with save/load/quit, gamepad pass.

## Technical notes

Native UMG (CreateWidget from C++, no Blueprint assets) following the
LBBodyShopPrototypeRootWidget precedent, driven by the same collectors
the canvas HUD uses (CollectGroups/CollectManagement stay the single
source of truth). The canvas HUD remains behind a dev toggle until U3
reaches parity, then becomes debug-only.

## Research amendment (2026-08-20)

UI_RESEARCH_2026-08-20.md (111 findings across 7 game teardowns + 3
lenses, 20 load-bearing claims adversarially verified) amends this
design. Its ten rules and phase re-scope are adopted wholesale; the
governing changes:

- Phases re-scoped: U1 becomes FOUNDATIONS (Common UI, the single
  EStationStatus enum with shape+colour tokens, the canonical cars/hour
  windowed rate system, composite font with CJK fallback, type ramp with
  the 12px@1280x800 floor, UI scale slider) - every one a documented
  expensive retrofit in the genre. Surfaces follow: U2 top bar, U3 card
  strip, U4 detail panel, U5 alerts + onboarding.
- One status enum drives dots, panels and toasts; alerts are stateful
  conditions with severity ladders, never fire-and-forget events; every
  alert has a clearing player action.
- Every status names its cause; every panel navigates (chips jump the
  camera); one panel template, one verb grammar, locked now.
- Interaction grammar locked: Space pause, 1/2/3 speeds, keys 1-4 select
  shops, one primary action per panel.
- Colour never alone (Okabe-Ito palette + shape glyphs); all text FText
  through ICU formatters; German overflow and zh-Hans coverage checks in
  every screen's definition of done.
- Build mode stays deferred with visible modal chrome reserved; global
  pause and station Hold are separate verbs forever.
